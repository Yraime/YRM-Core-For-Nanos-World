## 📦 Aperçu & Fonctionnalités

`yrm-core` est un framework pour nanos world qui facilite la gestion des bases de données et la création de commandes personnalisées pour votre serveur.

### 🌟 Fonctionnalités incluses

- 🗄️ **Gestion des bases de données SQL :** Prise en charge de SQLite et MySQL.
- 💾 **Création automatique de SQLite :** Création automatique de la base de données SQLite si elle n'existe pas.
- 🔄 **Communication SQL :** Gestion de la communication avec les bases de données SQLite et MySQL.
- ⌨️ **Système de commandes :** Possibilité de créer des commandes personnalisées pour votre serveur.
- 🏷️ **Préfixe personnalisable :** Possibilité de définir le préfixe utilisé pour appeler les commandes.

---

## ⚙️ Dépendances

`yrm-core` constitue la base du framework YRM et est nécessaire au fonctionnement de `yrm-lib`.

Assurez-vous que `yrm-core` est installé et configuré avant d'utiliser les bibliothèques qui en dépendent.

---

## 🛠️ Configuration

### Base de données

`yrm-core` permet d'utiliser SQLite ou MySQL selon les besoins de votre projet.

- **SQLite :** La base de données est créée automatiquement si elle n'existe pas.
- **MySQL :** Permet de communiquer avec une base de données MySQL configurée pour votre serveur.

### Commandes

Le système de commandes permet de créer vos propres commandes et de définir le préfixe utilisé pour les appeler.

Pour découvrir les options de configuration et les exemples d'utilisation, consultez la [documentation officielle](https://yraime.github.io/yraime.docs/docs).
